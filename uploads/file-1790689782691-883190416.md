B1: cài đặt
- install package: yarn or yarn install 
- yarn build (build 1 lần duy nhất)

B2: start
- yarn start:dev (terminal: App is running on port 8081 in development mode --> start thành công)
nếu lỗi thì vào file server.ts comment đoạn redis
![alt text](<../../../Desktop/Screenshot 2026-07-04 at 9.07.35 PM.png>)

B3: tạo database (sao khi cài xong postgresql)
- yarn db:create
- yarn db:migrate
- yarn db:seed

*ghi chú:
"db:create": Tạo database
"db:drop": Xoá database
"db:seed": insert dữ liệu mẫu
"db:migrate": tạo table, tạo column, update table
"db:migrate:undo": xoá table, column
"migrations:create": tạo ra file migration để tạo bảng, update bảng VD:"sequelize migration:generate --jobs",
"seeders:create": tạo file seed để thêm data mẫu VD:"sequelize seed:generate --users",
